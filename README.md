# NexoByte Académico Web

Micrositio Astro estático para el caso ficticio NexoByte S.A.S. — UNAD, Tarea 3, grupo 102998054_66.

## Desarrollo local

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Estado S1 · v0.1

Landing responsive con contenido societario, cronología de formalización y supuesto SIAD. Las fichas de cinco anexos están visibles, pero los botones de visor y descarga permanecerán deshabilitados hasta preparar y revisar las versiones públicas de los PDF.

## GitHub Pages

Astro está configurado para usar el dominio de GitHub Pages y la ruta base `/nexobyte-academico-web/`. El sitio **no está publicado** y todavía no hay workflow de despliegue.

## Privacidad

No publicar formularios originales ni datos personales innecesarios. Las futuras copias deben estar redactadas y etiquetadas como simulación académica sin validez registral.
